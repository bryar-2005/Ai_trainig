# Ai_trainig

An English ↔ Kurdish Sorani subtitle translation and model-training project. The requested full product specification is recorded in [SPEC.md](SPEC.md).

## Project status

This repository is being built incrementally. Phase 0 establishes the repository conventions; no web service, model training, or inference engine is implemented yet. Dataset and checkpoint artifacts must remain local and untracked.

The Arena session uses the existing `bryar-2005/Ai_trainig` repository and its fixed session branch rather than reinitializing Git, creating a different remote, or pushing to `main`.

## Data and licensing

Use only subtitle files and parallel translations that you are authorized to process. Subtitle files and movie data can be copyrighted; do not scrape or redistribute them without permission. Do not commit private datasets, videos, secrets, or model weights.
